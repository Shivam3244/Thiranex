# 🔐 Task 01 – Password Strength Analyzer

## 📖 Description

A Python-based tool that evaluates the strength of user-entered passwords and provides recommendations for creating stronger passwords.

## ✨ Features

- Checks password length
- Checks uppercase characters
- Checks lowercase characters
- Checks numbers
- Checks special characters
- Classifies password strength
- Suggests stronger passwords
- Password hashing using PBKDF2-HMAC-SHA256
- Basic password reuse detection

## 🛠️ Technologies

- Python
- Regular Expressions
- hashlib
- PBKDF2
- os
